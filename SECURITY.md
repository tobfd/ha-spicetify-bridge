# Security Policy

## Supported Versions

We actively support the latest release of `ha-spicetify-bridge` with security patches.

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of `ha-spicetify-bridge` seriously. If you discover a security vulnerability (such as API key exposure, authentication bypass, or WebSocket injection risks), please **do not** open a public GitHub issue.

### How to report:
1. **GitHub Security Advisory (Preferred):** Report privately via [GitHub Security Advisories](https://github.com/tobfd/ha-spicetify-bridge/security/advisories/new).
2. **Email:** Send your report directly to **support@tobfd.de**.

### What to include in your report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal proof-of-concept to reproduce the issue.
- Any suggested fixes or mitigations (if available).

### Response Timeline:
- **Acknowledgment:** Within 48 hours.
- **Status Updates:** Regular updates regarding fix progress.
- **Credit:** You will be credited in the release notes upon patch release (unless you request to remain anonymous).
